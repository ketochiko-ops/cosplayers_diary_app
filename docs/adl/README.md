## プロダクト概要

コスプレ活動を端末内だけで管理するモバイル/PWAアプリです。主要な利用領域は次のとおりです。

- 日記: 月カレンダー、同日複数活動、コスプレ/カメラマン/その他の記録
- マスター: ジャンル、キャラクター、専用または汎用衣装
- カラコン: 製品、購入、1組単位の実物、日記ごとの使用履歴
- 写真: 原本または長辺2,048pxへ縮小したアプリ専用領域への保存
- 統計: 年別/全期間の活動回数、活動日数、月別値、ランキング、在庫
- データ交換: CSV生成・検証、ZIPバックアップ/復元
- 設定: 写真保存モード、最終バックアップから30日のリマインド

通常利用にアカウントやサーバーは不要です。PWAでは任意でローカルプロジェクトファイルまたはGoogle Drive APIへ同じJSONを保存できます。iOS・iPadOS・Androidに加え、ホーム画面追加とオフライン起動が可能なPWAを配信できます。

## 実装接続状況

「ロジックが存在する」ことと「ユーザーが画面から利用できる」ことを分けて扱います。

| 領域 | ドメイン/サービス | UI接続 | 永続化/バックアップ | 現状 |
|---|---:|---:|---:|---|
| 日記・カレンダー | 済 | 済 | 済 | CRUDと複製が利用可能 |
| マスターデータ | 済 | 一部 | 済 | 追加UIはキャラクターを先頭ジャンル、衣装を汎用として登録する簡易版 |
| カラコン製品・購入 | 済 | 済 | 済 | 製品と数量の追加が可能 |
| カラコン実物・使用 | 済 | 未接続 | 済 | 開封/使用ロジックはあるが日記フォームから操作不可 |
| 写真保存・縮小 | 済 | 未接続 | 未接続 | サービス単体のみ。写真メタデータもアプリ状態に未登録 |
| 統計 | 済 | 一部 | 状態から再計算 | 主要指標とキャラクター上位を表示。キャラクター名はマスターから解決 |
| CSV | 解析・検証・出力済 | 未接続 | ZIPへ出力 | 単独CSVインポートやCSVからの状態復元は未実装 |
| ZIPバックアップ | 済 | 済 | 済 | `app_state.json` を復元の正本に使用。画像はまだ同梱されない |
| PWAプロジェクト保存 | 済 | 済 | ブラウザ内JSONと任意の外部JSON | 対応ブラウザのファイル、またはOAuth接続中のGoogle Driveへ更新時保存 |
| SQLite正規化テーブル | スキーマ済 | 対象外 | 未接続 | 通常保存は `settings` 内JSONのみ |

## 現在の最重要ポイント

1. `AppShell` が `MasterDataStore`、`DiaryStore`、`LensStore` を生成し、画面へ直接渡します。
2. ストア変更は250msのデバウンス後、全状態を1つのJSONへ変換し、ネイティブではSQLite、Webではブラウザのローカルストレージへ保存します。PWAのプロジェクト保存が接続中なら同じJSONを外部にも保存します。
3. ZIPにはCSV一式と `data/app_state.json` が入りますが、復元に使うのは後者です。
4. 正規化SQLiteテーブルとCSVは将来の移行・相互運用向けで、現行ランタイムの正本ではありません。
5. 写真とカラコン使用を画面へ接続する場合、日記保存/編集/削除との原子的な整合性を新たに設計する必要があります。
