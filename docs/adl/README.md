## プロダクト概要

コスプレ活動をオフラインで管理し、任意でGoogleカレンダーへ同期できるモバイル/PWAアプリです。主要な利用領域は次のとおりです。

- 日記: 月カレンダー、同日複数活動、コスプレ/カメラマン/その他の記録
- マスター: 参加イベント、ジャンル、キャラクター、専用または汎用衣装
- カラコン: 製品、購入、1組単位の実物、日記ごとの使用履歴
- 写真: 原本または長辺2,048pxへ縮小したアプリ専用領域への保存
- 統計: 年別/全期間の活動回数、活動日数、月別値、ランキング、在庫
- データ交換: CSVサービス、JSON保存/読み込み・旧ZIP移行
- 設定: 写真保存モード、最終バックアップから30日のリマインド
- 任意連携: 専用の非表示可能なGoogleカレンダー、端末間の日記同期、Gemini向けの予定説明

通常利用にアカウントやサーバーは不要です。PWAは初回と設定で指定プロジェクトフォルダ（対応ブラウザ）またはブラウザ保存（Safari対応）を選びます。iOS・iPadOS・Androidに加え、ホーム画面追加とオフライン起動が可能なPWAを配信できます。

## 現在の最重要ポイント

1. `AppShell` が `MasterDataStore`、`DiaryStore`、`LensStore` を生成し、画面へ直接渡します。
2. ストア変更は250msのデバウンス後、全状態を1つのJSONへ変換し、ネイティブではSQLite、Webではブラウザのローカルストレージへ保存します。PWAのフォルダ保存モードが接続中なら画像を先に、同じJSONを後に指定フォルダへ保存します。
3. VercelのGit自動デプロイは無効で、`develop` の検証済みprebuilt成果物だけを本番へ昇格します。`pre-develop` はPagesに配信し、手動実行も両者のブランチ条件を守ります。
4. 新規保存は非圧縮JSON。旧ZIP移行時だけ `data/app_state.json` を読みます。
5. 正規化SQLiteテーブルとCSVは将来の移行・相互運用向けで、現行ランタイムの正本ではありません。
6. 日記画像は保存成功後に日記参照とメタデータを確定し、取り外しても過去の画像は残します。カラコン使用のUI接続は未実装です。
